# Вычислительный практикум, 4 семестр

Программы на Python и отчёты к заданиям.

## Структура
- `code/` — программы (Python 3; `numpy` и `scipy` — для заданий 4.1, 4.3, 6; `scipy` необязателен для 4.2 и 5)
- `Report_T/` — технические отчёты (`Report_T<номер>.docx`)
- `summaries/` — описание заданий (`Summary_Task_<номер>.docx`)

| № | Тема | Программа |
|---|------|-----------|
| 1 | Нелинейные уравнения: отделение корней, бисекция, Ньютон, модифицированный Ньютон, секущие; задача о шаре | `code/Task_1.py` |
| 2 | Алгебраическое интерполирование (Лагранж, Ньютон) | `code/Task_2.py` |
| 3 | Численное дифференцирование, оптимальный шаг | `code/Task_3.py` |

| 4.3 | Составные КФ, уточнение по Рунге–Ромбергу | `code/Task_4_3.py` |

## Запуск
```
pip install numpy scipy
python code/Task_1.py
```
Ввод интерактивный; пустой ввод (Enter) подставляет значение по умолчанию. Для заданий 1–6 доступны варианты из списка и ввод собственных данных.
